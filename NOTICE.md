# Notice

## Authorship

Dormify was created as a final-year Information Systems Engineering project
by a five-person team: Donia Hassan, Maha Kadah, Aya Abu-Raya, Zeinab
Habiballah and Siraj Sulieman. The product, its allocation model and core
workflows, and the original implementation, including the deployment and
handover work, are the work of that team.

After the academic project was completed and handed over, Donia Hassan
carried out a separate, independent engineering effort on the system,
referred to in this repository as Dormify v3: architecture, maintainability,
reliability, security and release readiness, while preserving the original
product behaviour. The README describes both phases.

## Scope of this repository

This is a sanitised engineering and portfolio snapshot. It intentionally does
not contain:

- production credentials, secret keys, tokens or environment files;
- operational student or resident records;
- operational housing-inventory exports;
- confidential institutional material or internal deployment details, such
  as hostnames, network addresses, infrastructure configuration or handover
  correspondence;
- institution-owned map assets.

Demo accounts, seed data, test fixtures and the output of the synthetic
student generator are synthetic. Names, identifiers, e-mail addresses
(`@example.edu`) and phone numbers in them do not refer to real people. The
screenshots in `docs/images/` were taken from a local installation running
that synthetic data set, not from any institutional deployment.

The repository makes no statement about the current operational status of
any institutional deployment of the system.
