# DORMIFY BACKEND - RESOLVED DEPENDENCY PINS
# ===========================================
# Pins the full resolved Python dependency graph - the direct
# dependencies and every package they pull in - so that an install
# produces the same versions every time instead of whatever happens to
# be newest on the day it runs.
#
# Direct dependencies stay declared in requirements.txt. This file does
# not add or remove dependencies; it only fixes what that declaration
# resolves to.
#
# Install with:
#     pip install -r requirements.txt -c constraints.txt
#
# Resolution is specific to the Python version it was produced on, so
# regenerate from a clean CPython 3.11 environment:
#     pip install -r requirements.txt
#     pip freeze > constraints.txt
#
# Regenerating changes the versions every build gets, so do it as a
# deliberate, reviewed dependency update - never as a side effect of an
# unrelated change.
# ===========================================
